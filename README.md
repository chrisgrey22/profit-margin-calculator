# Domestic Abuse Scene Support App

A lightweight, single-page app designed for officers attending domestic violence incidents.
It provides:

- Immediate safety prompts for critical threats.
- Structured risk indicators with a live risk score.
- Priority action recommendations based on assessed risk.
- Golden-hour evidence prompts.
- Victim-centred question prompts.
- Copyable summary for handover/report writing.

## Run locally

Open `index.html` directly in your browser, or serve the folder with any static server.

Example:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Important

This tool supports—not replaces—professional judgement, local policy, and legal requirements.
